## 1. Что это за проект
Дропшип-магазин термокружек Stanley для украинского рынка.
- **`shop.html`** — боевой магазин: SPA, hash-роутинг (`#home`, `#shop`, `#product?id=…`, `#cart`, `#checkout`, `#account`, `#wishlist`…), рендер на JS, данные о товарах инлайн. Бренд в шапке — `stanley_brand_ua`.
- **`admin.html`** — админ-панель (пароль по умолчанию `Stanley1913Admin!`). Пишет оверрайды товаров/цен в `localStorage` (`dua_admin_products`), которые магазин подхватывает.
- **`index.html` / `catalog.html` / `product.html`** — отдельные статичные лендинги (бренд `Stanley Brand UA`).
- **`docs/`** — ЗЕРКАЛО всего сайта, из него деплоится Pages. Держать в синхроне с корнем.
- **`tg-ttn-bot/`** — отдельный Telegram-бот для создания ТТН Новой Почты (не трогали в этой сессии; см. `CLAUDE.md`).

Язык интерфейса — украинский/русский. Новые строки — на украинском.

## 6. Тестовый харнесс (CDP) — как гонять
Сайт статический. Локальный прогон:
```bash
python3 -m http.server 8099        # из корня репо
# headless Chrome (в этой среде): /opt/pw-browsers/chromium-1194/chrome-linux/chrome
```
Для интерактивных E2E-тестов использовался драйвер **CDP на Node 22** (`scratchpad/cdp.mjs` + `t*.mjs`) — вложен в архив (`_test-harness/`). Ключевые уроки:
- `shop.html` — hash-роутинг; главная это **`#home`** (не `#/`, тот даёт 404). Основной контейнер — `#main`.
- **ВАЖНАЯ ловушка тестов:** навигация `Page.navigate` на тот же `#hash` — это same-document переход, скрипты НЕ перезапускаются. Чтобы применить свежий `localStorage`, нужен настоящий **reload** (`Page.reload`), а не смена хэша. Из-за этого сначала ложно казалось, что мост админки сломан.
- Модель кликов: `[data-quick-add]`/`[data-quick-color]` (в корзину), `[data-fav]` (избранное), `[data-card-color]`+`[data-pid]` (свотч), `[data-inc/dec/rem]` (корзина), `[data-brand]`/`[data-vol]` (фильтры), `[data-payment]`/`[data-shipping]`, язык — дровер `[data-lang]` → `[data-lang-set]`, чекаут — `#placeOrder`, согласие — клик по обёртке `#termsCh` (НЕ по `#termsBox`).
- Мин. ширина headless-вьюпорта — 500px (реальный <500 не отрисовать).
- `ffmpeg` в среде (`/opt/pw-browsers/ffmpeg-*`) урезан — не декодирует MP4.

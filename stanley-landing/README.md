# Лендинг Stanley Quencher 40oz (для трафіку з TikTok)

Окремий односторінковий сайт. Основний магазин (`stanley-brand-site/`, корінь репозиторію) не змінювався — звідти взято лише стиль, фото та дані товару.

```
stanley-landing/
├── index.html          розмітка (редагувати не потрібно)
├── config.js           ← ТУТ усе: ціна, назва, опис, кольори, фото, характеристики, тексти
├── assets/landing.css  стилі
├── assets/landing.js   логіка (форма, маска телефону, відправлення)
├── img/                фото
└── server/
    ├── server.js       сервер: віддає сайт + приймає замовлення (Telegram + файл)
    ├── .env.example    налаштування сервера (скопіювати в .env)
    └── test.js         автотести сервера
```

## Запуск

Потрібен лише Node.js 18+. Встановлювати залежності не треба.

```bash
cd stanley-landing
cp server/.env.example server/.env    # вписати TG_BOT_TOKEN і TG_CHAT_ID
node server/server.js                 # → http://localhost:8080
```

Замовлення надходять у Telegram і **завжди** дублюються в `server/data/orders.jsonl`: якщо Telegram недоступний, замовлення не загубиться.

Перевірка: `npm test` — 20 перевірок сервера.

## Як змінити товар — тільки `config.js`

| Що | Де в `config.js` |
|---|---|
| Ціна | `product.price: 2500` |
| Стара (закреслена) ціна | `product.oldPrice: 2899` — `null` прибирає знижку й мітку «−14%» |
| Назва / підзаголовок / опис | `product.name`, `product.tagline`, `product.description` |
| Мітка «Хіт продажів» | `product.badge` — `""` прибирає |
| Максимум штук | `product.maxQty` |
| Кольори та фото | `colors: [...]` — для кожного кольору `name`, `hex` (колір кружечка) і `images` (перше фото — головне) |
| Фото «в житті» | `lifestyleImage` |
| 4 плитки переваг | `highlights` |
| Характеристики | `specs` — порожнє `value: ""` приховує рядок |
| Комплектація | `inBox` |
| Пункти під кнопкою | `trust` |
| Будь-які написи | `texts` |
| Контакти (футер і повідомлення про помилку) | `brand` |
| Піксель TikTok | `tiktokPixelId` |

**Нове фото:** покладіть файл у `img/` (краще `.webp`, квадрат 800–1200 px, прозорий або світлий фон) і впишіть шлях, наприклад `"img/my-photo.webp"`.
Якщо змінили **перший** колір, оновіть також рядок `<link rel="preload" ...>` в `index.html` — так головне фото швидше завантажується.

**Додати колір:**
```js
{ id: "frost", name: "Іній", hex: "#D9D9DA",
  images: ["img/q40-frost-front.webp", "img/q40-frost-back.webp"] },
```
(`id` — латиницею, без пробілів.)

Після зміни `config.js` сервер підхоплює нові ціни сам, перезапуск не потрібен.

## Як працює замовлення

1. Кнопки «КУПИТИ» (перший екран, липка панель знизу, «Замовити» в шапці) ведуть до форми.
2. Форма: колір, кількість, імʼя, прізвище, телефон. Підсумок із сумою — над кнопкою.
3. Перевірки: імʼя/прізвище — лише літери (апостроф і дефіс дозволені); телефон автоматично форматується як `+380 67 123 45 67` і приймає `067…`, `+38 (067)…`, `380…`.
4. «ОФОРМИТИ ЗАМОВЛЕННЯ» → `POST /api/order`. Повідомлення «Дякуємо! Ваше замовлення прийнято» зʼявляється **лише** після того, як сервер підтвердив збереження.
5. Захист від дублів:
   - кнопка блокується на час відправлення;
   - кожне замовлення має номер (`TT261118-123456`), і сервер не створює те саме замовлення двічі;
   - якщо людина за 15 хв надсилає таке саме замовлення, сайт перепитує;
   - ліміт: 6 нових замовлень з одного IP за 10 хв;
   - приховане поле-пастка для ботів.
6. Ціну сервер бере з `config.js`, а не з браузера: підробити суму неможливо.
7. Якщо прийом не налаштовано (`order.endpoint: ""`), сервер не запущено або він не відповідає, сайт чесно пише «Замовлення НЕ надіслано» і дає посилання на Telegram/Instagram.

## Публікація

- **VPS / Render / Railway / Fly.io:** запускайте `node server/server.js`, а змінні з `.env.example` задайте в панелі хостингу. За проксі (nginx, Cloudflare) вкажіть `TRUST_PROXY=1`.
- **Статичний хостинг (Netlify, GitHub Pages) + окремий сервер:** у `config.js` вкажіть `order.endpoint: "https://ваш-сервер/api/order"`, а на сервері — `ALLOWED_ORIGINS=https://ваш-сайт`.
- Статичний хостинг **без** сервера не прийматиме замовлення. Сайт покаже, що замовлення не надіслано, і запропонує написати в Telegram/Instagram.

## Звідки дані

Ціни, кольори, характеристики та фото взято з основного сайту (товар `stanley-quencher-40`). Перед запуском реклами перевірте їх. Поля «Гарантія» та «Країна виробництва» залишено порожніми: даних про них немає.

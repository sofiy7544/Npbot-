## 🚀 ВСТАНОВЛЕННЯ

### Якщо вже є робочий сайт на хостингу

1. **Зроби бекап** поточної версії (просто скачай папку з хостингу).
2. Завантаж **усі файли** з цього архіву в корінь сайту (туди, де лежить `index.html`).
3. Перевір що з'явилися 2 нові файли: `mobile-cro-patch.css` і `mobile-cro-patch.js`.
4. Перевір що `index.html` має такі рядки (вони мають бути після оновлення):
   - У `<head>`: `<link rel="stylesheet" href="mobile-cro-patch.css">`
   - Перед `</body>`: `<script src="mobile-cro-patch.js"></script>`
5. Відкрий сайт у браузері (Ctrl+F5 для скидання кешу). Готово.

### Якщо це новий хостинг

Завантаж усі файли з цього архіву через FTP/cPanel/Netlify Drop у корінь.

### Локально для тестування

```bash
cd stanley-brand-site-patched
python3 -m http.server 8000
# Відкрий http://localhost:8000 у браузері
```

## 📞 ЩО ЩЕ МОЖНА ПОКРАЩИТИ

Поза цим патчем (потребує редагування основного коду):

- Виносити inline CSS (2600 рядків) у зовнішній `styles.css` — швидкість завантаження
- Виносити inline JS (4700 рядків) у зовнішній `app.js` з `defer`
- Замінити inline data-URI SVG placeholders (123KB) на дрібні файли
- Додати `<picture>` з `srcset` для hero — економія трафіку 2-3×
- Lazy-render для `<details>` accordion на PDP

Це **performance**-оптимізації. На UX/CRO вже не впливають. Якщо буде час — зроблю окремий performance-патч.

### Реферальна система
1. Користувач реєструється
2. Копіює своє реф-посилання з Кабінету (формат `?ref=REF-XXXXXX`)
3. Друг переходить → робить **першу покупку** → автоматично:
   - Друг отримує welcome-знижку 50% на наступне замовлення
   - Реферер отримує **50% кешбек** від суми покупки друга на свій баланс

### Email сповіщення (потрібна 1-разова налаштування EmailJS)
Без EmailJS все працює, тільки немає листів. Підключити можна потім.
- **Як налаштувати:** див. `EMAILJS-SETUP.md`
- **Де:** `admin.html` → Контакти / Brand → 📧 EmailJS

### Накладений платіж
- При виборі накладки автоматично + 200 ₴ передоплата
- Користувач вибирає спосіб передоплати: Privat24, Mono, або LiqPay (картка)
- Apple/Google Pay приховуються (не потрібні при накладці)

### Автозаповнення на checkout
- На iPhone iOS-Contacts picker працює (як у твоєму відео)
- На Mac/Windows — браузер автозаповнює з збережених контактів

## 🚀 Як запустити сайт

### Варіант А: Хостинг "за 5 хвилин" (рекомендований)

#### 1. Netlify Drop (найшвидше)
1. Відкрий [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетягни папку `dailyua-site/` на сторінку
3. Через 30 секунд отримаєш URL виду `dreamy-curie-12345.netlify.app`
4. Безкоштовний хостинг, SSL автоматичний

#### 2. Cloudflare Pages
1. Зареєструйся на [https://pages.cloudflare.com](https://pages.cloudflare.com)
2. Створи проект → завантаж архів
3. Безкоштовний домен `*.pages.dev`, SSL автоматичний

#### 3. GitHub Pages
1. Створи репозиторій на GitHub
2. Завантаж усі файли в нього
3. Settings → Pages → main branch → Save
4. Сайт доступний на `username.github.io/repo-name`

### Варіант Б: Власний хостинг

Якщо у тебе вже є хостинг (Ukraine.com.ua, Hostpro, Hostiq, тощо):
1. Відкрий FTP/cPanel/файловий менеджер
2. Завантаж усі файли в папку `public_html` (або `www`, або корінь сайту)
3. Перевір що `index.html` відкривається за основним URL

### Варіант В: Запуск локально (тестування)

```bash
cd dailyua-site
python3 -m http.server 8000
```
Відкрий у браузері `http://localhost:8000`. Адмінка — `http://localhost:8000/admin.html`.

Або просто **подвійний клік** по `index.html` — теж працює, але деякі функції (типу sitemap) будуть обмежені.

## 🔌 Підключення власного домену

Купив домен (`dailyua.com.ua`)? Прив'язуй так:

### Якщо хостинг Netlify:
1. Domain settings → Add custom domain → введи `dailyua.com.ua`
2. У реєстратора домену (там де купував) → DNS → додай:
   - **Тип A**, ім'я `@`, значення `75.2.60.5`
   - **Тип CNAME**, ім'я `www`, значення `your-site.netlify.app`
3. Через 1-24 години сайт буде на твоєму домені, SSL налаштується автоматично

### Якщо хостинг Cloudflare Pages:
1. Custom domains → Set up a custom domain
2. Cloudflare сам пропише DNS, якщо домен теж у нього
3. Якщо не в Cloudflare — переключи nameservers згідно інструкцій

## 🛍 Як додавати товари

### Через адмінку (швидко, для перегляду)

1. Зайди в адмінку (`/admin.html`)
2. **Товари** → **+ Додати товар**
3. Заповни форму у 4 вкладках:
   - **Основне:** бренд, ID (наприклад `stanley-iceflow-25`), назва, об'єм, кількість кольорів, опис
   - **Ціни/Залишок:** ціна, стара ціна (для перекреслення), кількість на складі, рейтинг
   - **Фото:** шлях до головного фото (попередньо завантаж його у **Медіатека**)
   - **Статуси:** позначки «Хіт», «Новинка»
4. Натисни **«Створити товар»**
5. Товар одразу з'являється в каталозі — але **тільки на твоєму пристрої!**

### Щоб товар побачили клієнти — експортуй у код

Адмінка зберігає зміни у localStorage **твого браузера**. Інші користувачі бачитимуть стандартний каталог. Щоб опублікувати:

1. Адмінка → **Експорт у код**
2. Натисни **⬇ Завантажити patch.js**
3. Відкрий файл `index.html` у текстовому редакторі (рекомендую безкоштовний [VS Code](https://code.visualstudio.com))
4. Знайди рядок `const PRODUCTS = [` (приблизно рядок 2874)
5. Виділи весь блок до закриваючої `];`
6. Заміни на блок `PRODUCTS_v2` з `patch.js`
7. Збережи файл і завантаж на хостинг

⚠️ Це **не складно**, але страшно перший раз. Якщо невпевнений — попроси знайомого програміста зробити це разом.

## 💰 Як змінити ціни

### Швидкий спосіб (для тебе на твоєму пристрої)
1. Адмінка → **Товари**
2. Натисни ✏️ біля товару
3. Вкладка **Ціни/Залишок** → зміни «Ціна, ₴» і збережи

### Постійний спосіб (для всіх клієнтів)
Те саме + потім **Експорт у код** → правка `index.html` (див. секцію вище).

### Масові зміни цін
Якщо треба змінити ціни на всі товари (наприклад, +15% через інфляцію):
1. Відкрий `index.html` у редакторі
2. Знайди `const PRODUCTS = [`
3. Знайди-замінити (Ctrl+H) — `"price": 1799` → `"price": 2069`, і так для кожної ціни
4. Збережи і завантаж

Або через адмінку — змінюй кожен товар вручну, потім один експорт.

### Як додати нові фото

#### Через адмінку (рекомендовано):
1. **Медіатека** → перетягни фото у dropzone
2. Адмінка автоматично:
   - Зменшить розмір до 1024px (більші не потрібні)
   - Сконвертує у WebP (зменшує вагу на 60%)
   - Збереже у браузері (localStorage)
3. Після завантаження клікни на фото → ім'я скопіюється в clipboard
4. Встав це ім'я у поле «Шлях до головного фото» товару

#### Постійно (для production):
Адмінка зберігає фото локально, але для production їх треба покласти у папку `img/`:
1. Підготуй фото (в ідеалі 800-1200px по довшій стороні, формат WebP)
2. Назви розумно: `brand-color-angle.webp`, наприклад `stanley-quencher-30-cream-front.webp`
3. Завантаж файли у `img/` через FTP/cPanel
4. У товарі вказуй `img/назва-файлу.webp`

#### Поради по фото
- Розмір: **до 1500px** по довшій стороні достатньо
- Формат: **WebP** (найкраще) або JPG (якщо не можна WebP)
- Вага одного фото: **до 100 КБ** (бажано 30-50 КБ)
- Конвертер онлайн: [squoosh.app](https://squoosh.app) (від Google, безкоштовно)

## 💾 Бекапи

### Чому це важливо
Адмінка зберігає все у браузері. Якщо очистиш кеш — втратиш зміни. Тому:

## 📊 Аналітика

### Що показує адмінка:
- Кількість замовлень
- Виторг (сума всіх замовлень)
- Середній чек
- Топ-5 товарів
- Розподіл замовлень по статусах

### Що рекомендую підключити (5-15 хв роботи):

#### Google Analytics 4 (безкоштовно, must-have)
1. Зареєструйся на [analytics.google.com](https://analytics.google.com)
2. Створи property → отримай Measurement ID (`G-XXXXXXX`)
3. Додай у `index.html` перед `</head>`:
   ```html
   <!-- Google Analytics -->
   <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
   <script>
     window.dataLayer = window.dataLayer || [];
     function gtag(){dataLayer.push(arguments);}
     gtag('js', new Date());
     gtag('config', 'G-XXXXXXX');
   </script>
   ```
4. За 24 години побачиш статистику відвідувачів

#### Plausible (privacy-friendly, $9/міс)
Альтернатива GA4, без cookie-баннера, GDPR-compliant. Просто скрипт у head.

#### Meta Pixel (для реклами в Instagram/Facebook)
Якщо плануєш рекламу:
1. [business.facebook.com](https://business.facebook.com) → Events Manager → Create Pixel
2. Додай скрипт у `index.html`

## 🆘 Часті питання

### "Я зробив зміни в адмінці, але клієнти їх не бачать"
Це нормально. Адмінка зберігає у твоєму браузері. Щоб клієнти побачили — **Експорт у код** + правка `index.html`.

### "Забув пароль адмінки"
1. Відкрий браузер у режимі **DevTools** (F12) → **Application** → **Local Storage** → видали ключ `dua_admin_pwhash`
2. Перезавантаж сторінку — пароль повернеться до `admin1234`
3. **Або** очисти весь localStorage (Ctrl+Shift+Del → Clear browsing data)

### "Сайт повільний"
Перевір розмір фото у папці `img/`. Якщо є фото >200 КБ, оптимізуй через [squoosh.app](https://squoosh.app).

### "Хочу прийняти онлайн-оплату"
Зараз checkout відкриває Telegram. Для реальних платежів треба інтеграція з:
- **WayForPay** (для Privat24, Mono, Visa/MC) — найпопулярніше в Україні
- **LiqPay** (Privat Bank)
- **Stripe** (міжнародні картки, для PL/EN клієнтів)

Це потребує **backend** (Node.js/PHP сервер), див. Етап 2 у дорожній карті.

### "Хочу додати ще одну мову (Deutsch, Français)"
1. Відкрий `index.html` → знайди `const I18N = {`
2. Скопіюй блок `en: { ... }` і встав з новим ключем `de: { ... }`
3. Переклади всі рядки
4. Додай у списку перемикача мов (знайди `<option value="en">EN</option>`)

### "Як видалити товар назавжди"
Адмінка → **Товари** → ✏️ → вкладка **Статуси** → ✓ «Вимкнути товар». Зникне з каталогу, але дані зберігаються (можна повернути).

Щоб видалити повністю — це треба робити у `index.html` (видалити блок з масиву PRODUCTS).

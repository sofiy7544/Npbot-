# Instagram-набір Stanley (@stanley_brand_ua)

- `out/` — готові картинки (PNG): `avatar.png`, `posts/` (10 постів 1080×1350), `stories/` (3 сторіс 1080×1920), `highlights/` (6 обкладинок «Актуального»).
- `guide/index.html` — інструкція для iPhone: акаунт, збереження фото, профіль, 10 постів у порядку публікації (з прямими посиланнями й підписами), Direct, план на 2 тижні.
- `guide/stanley-instagram-photos.zip` — усі 20 картинок одним архівом; пости названі step01…step10 у порядку публікації.
- `guide/i/` — ті самі картинки в JPG (на них ведуть прямі посилання raw.githubusercontent.com).
- `data.js` — ціни, моделі, кольори, умови доставки/оплати. Змінили → `node build.js` → нові картинки в `out/`.
- `img/` — вирізані фото товарів (з основного сайту).

Ціни — як на лендингу (`stanley-landing/config.js`); умови доставки й оплати — з основного сайту. Перевірте перед публікацією.

# 💡 Smart Lamp Bot — лампа с интеллектом

Telegram-бот: пишешь лампе **обычным языком**, GPT понимает намёк и переводит его
в команды, лампа выполняет и **отвечает от своего лица** (с характером). Плюс
кнопки быстрых действий и картинка текущего света прямо в чат.

> «сделай потусклее и потеплее» · «мне режет глаза» · «врубай киношный свет» ·
> «стань фиолетовой» · «что-то мрачно» · «романтика»

## Что умеет
- Вкл/выкл, яркость (абсолютно и «ярче/тусклее»), тёплый↔холодный белый, любой цвет RGB.
- Готовые сцены: `утро, день, вечер, ужин, чтение, работа, кино, ночник, романтика, вечеринка, релакс`.
- Понимает **намёки и настроение** через GPT (а не только точные команды).
- Работает **без оборудования** — встроенный симулятор рисует лампу картинкой.
- Работает **без AI-ключа** — откатывается на простой парсер команд.

## Архитектура (слоями, чтобы легко менять железо)
```
bot.py     Telegram (aiogram): сообщения, кнопки, отправка картинки
brain.py   «интеллект»: текст -> действия + ответ. GPT, с фолбэком на правила
lamp.py    состояние лампы + ДРАЙВЕРЫ железа (sim / yeelight / …) + сцены
render.py  рисует текущее состояние лампы в PNG (Pillow)
```
«Что сделать» (brain) и «через что светить» (драйвер в lamp.py) разделены —
добавить новую лампу = написать один класс-наследник `LampDriver`.

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env         # впиши TG_BOT_TOKEN (от @BotFather)
python bot.py
```
Напиши боту `/start`.

- **Без OpenAI-ключа** — бот сразу работает на правилах (точные команды, базовые намёки).
- **С ключом** (`OPENAI_API_KEY` в `.env`) — включается настоящий «интеллект»:
  лампа понимает фразы вроде «хочу уюта» или «слишком официально горит».

## Подключение настоящей лампы
Пока стоит `LAMP_BACKEND=sim` (симулятор). Для реальной лампы:

### Yeelight / Xiaomi (готово из коробки)
1. В приложении Yeelight включи **«Режим LAN / Для разработчиков»** у лампы.
2. Узнай IP лампы в роутере/приложении.
3. В `.env`:
   ```
   LAMP_BACKEND=yeelight
   YEELIGHT_IP=192.168.1.50
   ```
4. `pip install yeelight` (уже в requirements) и перезапусти.

### Другая лампа (Tuya/Smart Life, TP-Link Tapo, ESP/Tasmota…)
Напиши класс в `lamp.py`:
```python
class MyLamp(LampDriver):
    def apply(self, state: LampState) -> None:
        # перевести state (power/brightness/mode/kelvin/rgb) в вызовы твоего API
        ...
```
и зарегистрируй его в `make_driver()`. Остальной код менять не нужно.

## Безопасность
- `.env` с реальными токенами **не коммить** (он в `.gitignore`). В git — только `.env.example`.
- `ALLOWED_USERS` в `.env` ограничивает, кто может командовать лампой (по Telegram ID).

# WLED Telegram Bot

Красивое и быстрое управление WLED-лампой из Telegram. Бот шлёт те же команды
в WLED JSON API, что и официальное приложение, но через удобную **живую панель**.

- 📊 **Живая панель** — одно сообщение показывает питание, шкалу яркости, цвет и
  эффект, и обновляется прямо на месте после каждого действия (без спама).
- ⚡ **Быстрый отклик** — постоянное keep-alive соединение с лампой.
- ⏻ Питание вкл/выкл одной кнопкой, яркость −/+ и пресеты 25/50/75/100 %.
- 🎨 Цвета, ✨ эффекты, 🎵 аудио-режим (звукореактивные эффекты).
- Имя устройства и список эффектов подтягиваются прямо с лампы.
- 📱 **Веб-приложение для телефона** — встроенный сервер отдаёт красивую
  страницу; добавь её на экран «Домой» айфона, и получишь иконку-приложение.
- ⏱ **Таймеры авто-выключения** лампы и телевизора (sleep-таймер).
- 🎤 **Голосовое управление** (кнопка-микрофон в приложении): «включи свет»,
  «сделай погромче», «включи на ютубе …» и т.п.

## 📱 Приложение на телефоне (айфон/андроид)

Вместе с ботом запускается мини веб-приложение. После старта в окне будет
строка вида `📱 Приложение для телефона: http://192.168.1.50:8080`.

На айфоне (в одной WiFi с ПК):
1. Открой этот адрес в **Safari**.
2. Кнопка **«Поделиться»** → **«На экран „Домой"»** → «Добавить».
3. Появится иконка — открывается на весь экран, как обычное приложение.

Порт меняется через `WEB_PORT` в `.env` (0 — выключить веб-приложение).

### 📺 Пульт для телевизора Samsung

В приложении есть вкладка **«ТВ»** — пульт с кнопками навигации (питание,
громкость, каналы, стрелки + OK, назад, меню, источник) для управления
телевизором Samsung по WiFi (без Bluetooth).

1. В приложении открой вкладку **«ТВ»** → **📡 Найти телевизоры в сети** —
   приложение само найдёт Samsung по SSDP и подставит IP (пульт не нужен).
   Либо впиши IP вручную (ТВ → Настройки → Сеть → Состояние) и нажми **OK**.
2. Нажми любую кнопку — при **первом** разе телевизор спросит
   «Разрешить устройство?» → подтверди на ТВ (кнопкой-джойстиком на корпусе,
   если пульт потерян).

Поддерживаются оба протокола Samsung: WebSocket (модели 2016+, нужна
библиотека `samsungtvws` — ставится автоматически) и Legacy (2014-2015,
порт 55000, без доп. библиотек). Протокол определяется автоматически.

## 🧠 Интеллект (GPT) — понимание свободной речи
По умолчанию бот разбирает команды по ключевым словам (быстро, без интернета).
Если задать ключ `OPENAI_API_KEY` в `.env` — включается умная подстраховка: когда
правила не поняли фразу, её разбирает GPT и всё равно выполняет. Тогда работают
живые формулировки:

- «сделай чтобы было уютно» → тёплый приглушённый свет
- «что-то скучно, оживи комнату» → яркий цветной
- «приглуши свет и поставь телик потише» → сразу лампа + ТВ
- «мне режет глаза» → тусклее

Реализация — `ai_brain.py` (подключён как fallback в `voice.py`). Модель
задаётся в `AI_MODEL` (по умолчанию `gpt-4o-mini` — дёшево и шустро). Нет ключа
или нет сети — бот просто работает на правилах, как раньше.

## 🎨 Оформление
В `assets/` лежит фирменная графика (иконка приложения + баннер), генерится
скриптом `python assets/make_assets.py`. Иконка и PWA-манифест уже подключены в
веб-приложении — при «добавить на экран „Домой"» на телефоне будет красивая
иконка, а не скриншот. Баннер бот шлёт в приветствии на `/start`.

## Настройка (3 значения)
1. **Токен** — у [@BotFather](https://t.me/BotFather): `/newbot` → выдаст токен.
   Лучше задать через окружение: `export WLED_BOT_TOKEN="твой_токен"`.
2. **WLED_IP** — по умолчанию `192.168.1.106`. Если IP лампы другой, поправь
   `WLED_IP`.
3. **ALLOWED_USERS** — свой Telegram ID узнать у [@userinfobot](https://t.me/userinfobot).
   Без него бот никого не пустит (это защита: лампой рулишь только ты).

Удобнее всего скопировать `.env.example` → `.env` и заполнить:

```bash
cp .env.example .env
```

| Переменная       | Описание                                        |
|------------------|-------------------------------------------------|
| `WLED_BOT_TOKEN` | Токен бота от @BotFather                         |
| `WLED_IP`        | IP-адрес WLED, например `192.168.1.106`         |
| `ALLOWED_USERS`  | Telegram ID через запятую                        |

## Установка в один клик (Windows)
1. Поставь **Python** с python.org (галочка «Add Python to PATH»).
2. Двойной клик по **`УСТАНОВКА.bat`** — поставит библиотеки и спросит 4 значения
   (токен бота, твой Telegram ID, IP лампы, ключ OpenAI), создаст `.env`.
3. Запуск — **`Запустить_бота.bat`**.

### Сменился Wi-Fi дома? (важно)
Если поменялся роутер/имя сети/пароль, нужно два шага:
1. **Переподключить саму лампу и телевизор к новой сети** (ПК-бот тут не
   поможет — устройства просто не будут в сети):
   - **WLED-лампа**: при потере Wi-Fi она поднимает свою точку доступа
     `WLED-AP` (пароль `wled1234`). Подключись к ней с телефона → откроется
     страница → впиши новую сеть и пароль. (Или через приложение WLED.)
   - **Телевизор**: Настройки → Сеть → подключить к новой Wi-Fi.
2. **IP лампы почти наверняка изменился.** Ничего искать вручную не нужно:
   - бот при старте сам проверяет лампу и, если не отвечает, **ищет её в сети**
     и прописывает новый IP в `.env`;
   - вручную узнать IP: команда **`/find`** в Telegram (или `python find_lamp.py`).
   - Телевизор ищется кнопкой «📡 Найти телевизоры» во вкладке «ТВ».

### Диагностика ПК (для оптимизации)
Двойной клик по **`ДИАГНОСТИКА.bat`** соберёт технический отчёт о ПК
(железо, автозапуск, процессы, занятость диска, службы, план питания) в
`setup/pc-reports/pc-report_*.json`. По нему можно понять, что тормозит ПК и
что отключить/почистить. **Важно:** собирается только техническая информация —
личные файлы, фото, пароли и браузер НЕ трогаются, и ничего никуда не
отправляется (отчёт остаётся локально, ты сам решаешь, делиться ли им). Код
открытый — `setup/pc_report.py`.

## Запуск в один клик

### Windows
1. Установи Python с https://www.python.org/downloads/
   — при установке обязательно поставь галочку **«Add Python to PATH»**.
2. Дважды кликни **`Запустить_бота.bat`**.
3. При первом запуске он спросит 3 значения (токен, твой Telegram ID, IP лампы)
   и сохранит их в файл `.env`. Дальше — просто двойной клик по этому же файлу.

### Linux / macOS
```bash
bash run.sh
```
Тоже поставит зависимости и при первом запуске спросит настройки.

> Запускать нужно на ПК, который **в той же WiFi/сети, что и лампа**.
> Чтобы бот работал постоянно — не выключай этот ПК (или см. автозапуск ниже).

### Вручную (если нужно)
```bash
pip install -r requirements.txt
export WLED_BOT_TOKEN="твой_токен"
python3 wled_bot.py
```

### Docker
```bash
cp .env.example .env   # заполни значения
docker compose up -d --build
docker compose logs -f
```
> `network_mode: host` нужен, чтобы контейнер видел WLED в локальной сети.

## Команды
- `/start` или `/menu` — меню с кнопками
- `/on`, `/off`, `/toggle` — быстро
- `/fxlist` — вывести **реальный** список эффектов с лампы (с индексами)

## 🎵 Аудио-режим — важно
Звукореактивные эффекты (Эквалайзер/GEQ, Водопад, Matripix и т.д.) работают
**только если** на лампе:
1. прошивка с usermod **AudioReactive** (Sound Reactive build), и
2. подключён **микрофон** (цифровой INMP441 или аналоговый).

Если этого нет — кнопки в разделе «Аудио» включат обычный эффект по этому
номеру (или ничего внятного). Проверить наличие аудио-эффектов: пришли боту
`/fxlist` — в списке должны быть названия вроде `GEQ`, `Waterfall`, `Matripix`,
`Gravimeter`. Если индексы другие — поправь словарь `AUDIO` в `wled_bot.py`.

## ⚠️ Где запускать (главное про сеть)
Бот общается с Telegram через интернет, но команды лампе шлёт на локальный
адрес (`192.168.x.x`). Значит **бот должен работать внутри домашней WiFi**:

- **Дома на железе** (Raspberry Pi / старый ПК / мини-сервер в той же сети) —
  проще всего. Для 24/7 настрой автозапуск через `wled-bot.service`.
- **VPS + Tailscale/WireGuard** — если хочешь рулить из любой точки: ставишь
  туннель дома и на сервере, бот достаёт лампу по приватному адресу. Лампа при
  этом НЕ торчит в открытый интернет.
- **Проброс порта наружу** — не делай, это дыра в безопасности.

Запустишь бота вне домашней сети без туннеля — кнопки будут отвечать
«Лампа недоступна», потому что `192.168.x.x` из интернета не виден.

## Автозапуск (Linux, systemd)
```bash
sudo cp wled-bot.service /etc/systemd/system/
# впиши токен и путь внутри файла
sudo systemctl daemon-reload
sudo systemctl enable --now wled-bot
journalctl -u wled-bot -f   # логи
```

- Не публикуй токен. Если засветился — перевыпусти:

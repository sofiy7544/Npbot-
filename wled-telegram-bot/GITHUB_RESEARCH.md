# GITHUB_RESEARCH — использованные решения и обоснование

Оценка выполнена по инженерным знаниям о проектах (без живого обхода GitHub в
этой среде — актуальные версии стоит перепроверить перед продом). Главный фильтр
— **целевое железо: ноут Atom / 4 ГБ ОЗУ**.

| Проект/библиотека | Назначение | Решение | Почему |
|---|---|---|---|
| `python-telegram-bot` | Telegram-бот | **Используем** (уже в проекте) | зрелая, async, v21 |
| OpenAI Python SDK | GPT/Whisper/эмбеддинги | **Используем** | единственный реалистичный AI на 4 ГБ ОЗУ |
| `samsung-tv-ws-api` (samsungtvws) | Samsung TV | **Используем** (в tvremote) | покрывает ws/token, проверено |
| `numpy` | косинус для памяти | **Используем** | брутфорс-поиск по тысячам записей — мгновенно, без сервиса |
| `psutil` | диагностика/управление ПК | **Используем** | кроссплатформенно, легко |
| Whisper / `faster-whisper` | распознавание речи | **Облачный Whisper**, локальный отложен | локальный на Atom слишком медленный |
| Ollama | локальные LLM | **Отклонено** | требует 3–4+ ГБ ОЗУ — нет на целевом ПК |
| Qdrant | векторная БД | **Отклонено** | отдельный сервис избыточен; SQLite+numpy достаточно |
| Home Assistant | универсальный слой устройств | **Отложено (адаптер позже)** | тяжёлый; наши WLED/TV работают напрямую |
| MCP SDK | интеграция инструментов | **Задел есть** (ToolRegistry совместим по духу) | полноценный MCP — отдельный этап |
| ha-agent-telegram / AI Butler | референс-архитектуры | **Идеи, не код** | взяли принципы: единый мозг, роутинг, инструменты |

## Лицензии
Используем библиотеки через pip (их лицензии — MIT/Apache/BSD/PSF). Чужой код
целиком не копировали; интеграция — через публичные API и собственные адаптеры.

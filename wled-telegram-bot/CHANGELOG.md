- Тесты: `test_panel.py` (старый .env не выводит в интернет), `test_web.py` (403 не из
  дома, без CORS), `test_site.py` (сайт не ходит на внешние адреса); всего 471.

## 2.3.0 — 2026-11-14

- **Один сайт вместо двух** (`site/`): свет (колесо, эффекты, сцены, таймер), пульт ТВ
  (D-pad, цифры, приложения, YouTube-поиск, поиск ТВ), ассистент (чат + голос,
  подтверждения), дом (автоматизации, задачи, память), ПК. Отдаётся ботом на :8090 и
  публикуется как статика на GitHub Pages. Старый пульт :8080 выключен (`WEB_PORT=0`).
- **Единый API** на :8090 под паролем и лимитами: `/api/lamp/*`, `/api/timer`, `/api/tv/*`,
  `/api/chat/confirm|cancel`, `/api/panel`, `/api/ping`; CORS для сайта с другого домена.
- **Доступ из интернета**: туннель Cloudflare (`tunnel.py`, без аккаунта) при `TUNNEL=1`
  и надёжном `ACCESS_PASSWORD` (слабый/5750 → туннель не поднимается). Адрес приходит в
  Telegram (`/panel`), при наличии `GITHUB_TOKEN` бот сам пишет его в `api.json` сайта.
- **По итогам второго раунда скептиков:** один «пропустил N сообщений» даже на медленной
  очереди и при врущих часах ПК; питание ТВ — только по явной просьбе рядом со словом
  «телевизор» (вопросы «телек включен?» не трогают питание; «да» на уточнение бота —
  работает); `tv.json` перечитывается целиком; `find_lamp.py` сначала проверяет адрес
  из `.env` и не пугает «не найдена».
- Тесты: `test_site.py` (браузер, Playwright), `test_panel.py`, `test_tunnel.py`; всего 491.

## 2.2.1 — 2026-11-14

- **Телевизор: одно соединение вместо нового на каждое нажатие.** Раньше каждая
  кнопка открывала новую сессию к ТВ и не закрывала её → ТВ выдавал новый токен
  каждый раз, а на экране копились «Произошла ошибка сети». Теперь соединение одно,
  закрывается корректно, переподключается само; токен ТВ в журналы не пишется.
- **Лампа при старте без ложной тревоги:** несколько попыток, скан сети 2 с на адрес;
  «не найдена» — только если лампа молчит и через полминуты после запуска.
- Тесты: `test_tvremote.py` (фейковый ТВ), `test_find_lamp.py`; всего 330.

## 2.1.0 — 2026-11-14

Всё ниже — после коммита `99d3a52` (дальше git в облачной сессии был недоступен;
источник истины — архив).

### Запуск на ПК
- `START.bat` без вложенных if-блоков (goto), ASCII, CRLF; окно не закрывается молча.
- Коды выхода бота: **2** — проблема в `.env` (шаблонный/неверный токен) → Блокнот и стоп
  вместо бесконечного перезапуска; **3** — уже работает другая копия → стоп с объяснением.
- Автозапуск: ярлык `INTELLECT.lnk` в «Автозагрузке», переписывается при каждом запуске
  (путь в Unicode через PowerShell — не ломается на і/ґ); запасной — Планировщик задач;
  старая задача `INTELLECT` удаляется. Подтверждено на ПК пользователя.
- Одна копия бота: замок-порт 47831 + `ConflictWatch` (серия 409 Conflict останавливает
  только ТОЛЬКО ЧТО запущенную копию; давно работающая остаётся).
- Найденный автопоиском IP лампы доходит и до ядра ИИ.
- `.env` читается с BOM/в чужой кодировке без падений.
- Чистка остатков прерванной установки pip.

### Питание ПК
- Перезагрузка/выключение: задержка не меньше 20 с (ИИ передавал 0).
- `/cancel` спрашивает саму Windows (`shutdown /a`) — работает и после перезапуска бота.
- Смена таймера снимает прежний (иначе Windows отказывала, а бот врал о времени).
- Кнопка «Отмена» отменяет только свой вопрос; кнопки исчезают после нажатия.

### Журналы `logs\`
- `start.log` (шаги START.bat), `bot.log`, `crash.log` (падения, в т.ч. до старта и в
  потоках), `diag.txt` (версия, окружение, лампа, автозапуск, причина остановки), `pip.log`.
- Токен бота и ключи во всех журналах заменяются на `***`.
- `REPORT.bat` → `diaglog.py --report`: упаковывает и открытые ботом журналы, повторно
  скрывает секреты, без `.env` и переписки.
- Версия сборки в `diag.txt`, `bot.log`, `start.log`.

### Передача дел и сборка
- `HANDOFF.md`, `VERSION`, `BUILD_INFO.txt`.
- `tools/build_release.sh` (сборка, CRLF, паспорт, `.env` пользователя внутрь, защита от
  утечки настоящих секретов), `tools/test_bats.sh` (проверка .bat в Wine), `tools/fakes/`.
- Из тестов убраны значения, похожие на настоящие секреты (теперь только выдуманные).

### Тесты
- `test_startup.py`, `test_diaglog.py`, расширен `test_computer.py` (имитация `shutdown.exe`).
- Каждый прогон тестов получает свой порт-замок (не мешают параллельные копии).

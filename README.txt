STANLEY QUOTE BOT — телеграм-бот для просчётов
================================================

Что делает: кидаешь боту ссылку на товар с www.stanley1913.com —
он сам берёт цену и вес, считает (наценка x1.5, почта $9/кг, 30 шт)
и присылает готовый PDF-просчёт.

--------------------------------------------------
УСТАНОВКА (один раз, ~5 минут)
--------------------------------------------------
1) Установить Python (если ещё нет):
   - Скачать с https://www.python.org/downloads/
   - При установке ОБЯЗАТЕЛЬНО поставить галочку "Add Python to PATH".

2) Создать бота и получить токен:
   - В Telegram найти @BotFather
   - Команда /newbot, придумать имя — он выдаст токен вида 123456789:AAH....
   - Открыть файл token.txt в этой папке, вставить токен одной строкой, сохранить.

3) Запустить: двойной клик по start.bat
   - Первый запуск сам поставит нужные библиотеки (нужен интернет).
   - Откроется чёрное окно с надписью "Бот запущен". Его НЕ закрывать.

--------------------------------------------------
КАК ПОЛЬЗОВАТЬСЯ
--------------------------------------------------
Написать своему боту в Telegram:

   ссылка                     -> 30 шт
   ссылка 50                  -> 50 шт
   ссылка 50 0.84             -> 50 шт + вес 0.84 кг/шт (если сайт вес не отдал)

Пример:
   https://www.stanley1913.com/products/classic-legendary-bottle-1-0-qt

В ответ придёт PDF.

--------------------------------------------------
НАСТРОЙКИ (если нужно поменять)
--------------------------------------------------
Открыть stanley_bot.py, вверху блок "НАСТРОЙКИ":
   MARKUP       = 1.5   (наценка)
   SHIP_PER_KG  = 9     (почта, $/кг)
   DEFAULT_QTY  = 30    (кол-во по умолчанию)

--------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
--------------------------------------------------
- "python не является внутренней командой" -> Python не в PATH,
  переустановить с галочкой "Add to PATH".
- Бот не отвечает -> проверь, что окно start.bat открыто и есть интернет.
- "В token.txt нет токена" -> вставь токен в token.txt и сохрани.
- Вес не подтянулся -> пришли ссылку с весом: "ссылка 30 0.84".
